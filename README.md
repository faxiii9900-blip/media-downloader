# Media Downloader (HD Video & Images)

Standalone web application to download maximum resolution videos (QuickTime / macOS compatible) and full-size images from YouTube & Instagram.

## One-Click Free Cloud Deploy

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/faxiii9900-blip/media-downloader)

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template?template=https://github.com/faxiii9900-blip/media-downloader)

## Features
- **Max Resolution Video**: Transcoded to H.264 (libx264) + AAC with `yuv420p` for 100% QuickTime & Apple device compatibility.
- **Image Mode**: Extracts highest resolution thumbnails and Instagram carousel photo albums.
- **15-Min Auto-Purge**: All temporary files are automatically pruned after 15 minutes.
